Accessibility Commitment

Target: WCAG 2.2 Level AA

Standards and Guidelines

ALMATRACE is committed to ensuring digital accessibility for all students, alumni, and coordinators. Key accessibility features include:

  • Full keyboard accessibility with visible high-contrast focus rings (:focus-visible).
  • Accessible semantic HTML structure with ARIA landmark roles and live regions for error alerts.
  • WCAG AA contrast ratios (minimum 4.5:1 for body text, 3:1 for headers).
  • Respect for prefers-reduced-motion system preferences.
  • Skip-to-content links on every page for efficient keyboard and screen-reader navigation.
